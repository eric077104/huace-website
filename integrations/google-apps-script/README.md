# 將官網表單連接至 Google 試算表

1. 開啟 Google 試算表「畫策整合行銷｜官網表單回覆」。
2. 選擇「擴充功能」>「Apps Script」。
3. 將本資料夾的 `Code.gs` 全部內容貼入 Apps Script 編輯器並儲存。
4. 開啟「專案設定」>「指令碼屬性」，新增 `FORM_SECRET`，值設為一組夠長且隨機的字串。可另外新增 `NOTIFY_EMAIL`，填入要接收新詢問通知的信箱；不設定則不寄通知。
5. 選擇「部署」>「新增部署作業」，類型選「網頁應用程式」；「執行身分」選「我」，「存取權」選「所有人」，然後部署並完成 Google 授權。
6. 複製部署網址（結尾為 `/exec`），在 Cloudflare Worker 的環境變數／Secrets 設定 `GOOGLE_SCRIPT_URL` 為該網址，並設定 `GOOGLE_SCRIPT_SECRET` 為與 `FORM_SECRET` 相同的字串。

試算表第一個工作表須維持下列欄位順序：送出時間、姓名、公司／品牌、Email、電話或 LINE、需求類型、預算範圍、預計開始時間、需求說明、同意個資告知、來源頁面。程式會在第一個工作表新增資料列。

每次修改 Apps Script 程式碼後，必須建立新的部署版本（「部署」>「管理部署作業」> 編輯 > 版本選「新增版本」> 部署），既有 `/exec` 網址即可繼續使用。
