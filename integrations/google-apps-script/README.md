# 將官網表單連接至 Google 試算表

此 Apps Script 是獨立專案，會使用 `SHEET_ID` 開啟試算表。

1. 前往 [script.google.com](https://script.google.com)，選擇「新專案」。
2. 將本資料夾的 `Code.gs` 全部內容貼入編輯器並儲存。
3. 開啟「專案設定」>「指令碼屬性」，新增以下屬性：
   - `FORM_SECRET`：設定一組夠長且隨機的私密字串。
   - `SHEET_ID`：填入目標 Google 試算表網址中的試算表 ID。
   - `NOTIFY_EMAIL`（選填）：填入要接收新詢問通知的信箱；不設定則不寄通知。
4. 選擇「部署」>「新增部署作業」，類型選「網頁應用程式」；「執行身分」選「我」，「存取權」選「所有人」，然後部署。
5. 完成授權。如果出現「Google 尚未驗證」畫面，這是自己的指令碼預期會看到的提示：選擇「進階」>「前往」>「允許」。
6. 複製部署網址（結尾為 `/exec`），在 Cloudflare Worker 設定 `GOOGLE_SCRIPT_URL` 為該網址，並將 `GOOGLE_SCRIPT_SECRET` 設為與 `FORM_SECRET` 相同的字串。

試算表第一個工作表須維持下列欄位順序：送出時間、姓名、公司／品牌、Email、電話或 LINE、需求類型、預算範圍、預計開始時間、需求說明、同意個資告知、來源頁面。程式會在第一個工作表新增資料列。

表單值會以純文字儲存，以保留電話等欄位的開頭零。

每次修改 Apps Script 程式碼後，選擇「部署」>「管理部署作業」> 編輯 >「新增版本」並部署；這會保留原本的 `/exec` 網址。
